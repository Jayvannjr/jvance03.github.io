My Personal Statement

I want my portfolio website to present my work in a simple, clear, and professional way. I believe that good web design should be easy to navigate and visually balanced. This project allows me to practice structure, styling, layout, and responsive design. I am especially interested in learning how different CSS tools work together, including floats, flexbox, grid systems, pseudo-classes, and positioning. As I continue building projects, I hope to become more confident in turning ideas into polished web pages that are both useful and visually appealing.
